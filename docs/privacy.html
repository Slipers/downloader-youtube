Politique de confidentialité

Dernière mise à jour : 31 octobre 2026

En bref : Downloader Youtube fonctionne entièrement sur votre ordinateur. Nous n'avons aucun serveur : vos vidéos, votre compte Google et vos données ne nous sont jamais transmis. Seul un avis sur l'application nous parvient, et uniquement si vous choisissez d'en laisser un.

1. Qui sommes-nous

Downloader Youtube est une application Windows gratuite et indépendante, non affiliée à YouTube ni à Google. Contact : slipamplemousse@gmail.com.

2. Données traitées sur votre ordinateur

Les éléments suivants restent sur votre PC, dans le dossier %LOCALAPPDATA%\DownloaderYoutubeer et dans les dossiers de téléchargement que vous choisissez :

  • vos préférences (thème, qualité, dossier de destination…) ;
  • les vidéos, miniatures et fichiers texte que vous téléchargez ;
  • si vous vous connectez à YouTube pour télécharger certaines vidéos, les cookies de session correspondants ;
  • si vous connectez une chaîne pour la publication, l'autorisation d'accès décrite ci-dessous.

Aucun de ces éléments n'est envoyé au développeur.

3. Publication sur YouTube (API Google)

La fonction « Publier sur YouTube » utilise les services d'API YouTube. Quand vous connectez une chaîne, l'application demande, via la page de connexion officielle de Google, les autorisations suivantes :

  • Mettre en ligne des vidéos sur votre chaîne (youtube.upload) : pour envoyer la vidéo que vous avez choisie, avec le titre, la description, la miniature, la visibilité et la date de programmation que vous avez saisis ;
  • Consulter votre compte YouTube (youtube.readonly) : uniquement pour afficher le nom et l'image de la chaîne connectée dans l'application.

Ces autorisations ne sont utilisées que lorsque vous lancez vous-même une publication. Les données (fichier vidéo, titre, description, miniature) partent directement de votre ordinateur vers les serveurs de Google, sans passer par un serveur tiers.

L'application ne voit jamais votre mot de passe Google. Elle conserve uniquement un jeton d'accès, chiffré sur votre ordinateur avec la protection de données de Windows (DPAPI), lisible seulement par votre session Windows. Ce jeton n'est jamais transmis au développeur ni à quiconque d'autre que Google.

L'utilisation et le transfert des informations reçues des API Google respectent le règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée (« Limited Use »). Ces informations ne sont ni vendues, ni partagées, ni utilisées à des fins publicitaires.

En utilisant la publication, vous acceptez les Conditions d'utilisation de YouTube. Les données traitées par Google le sont selon les Règles de confidentialité de Google.

4. Retirer l'accès

  • Dans l'application : bouton « Déconnecter » de la fenêtre de publication. L'accès est révoqué chez Google et le jeton est supprimé de votre ordinateur.
  • À tout moment depuis votre compte Google : myaccount.google.com/connections.

5. Ce qui sort de votre ordinateur

  • Téléchargements : l'application contacte les sites dont vous collez les liens, comme le ferait votre navigateur.
  • Mises à jour : l'application consulte GitHub pour savoir si une nouvelle version existe.
  • Avis facultatif : si vous choisissez de noter l'application, la note, votre commentaire et le numéro de version nous sont envoyés. Rien d'autre (ni nom, ni e-mail, ni adresse).

L'application ne contient ni publicité, ni traceur, ni outil de mesure d'audience.

6. Conservation et suppression

Les données restent sur votre ordinateur tant que vous ne les supprimez pas. Pour tout effacer : déconnectez votre chaîne, désinstallez l'application et supprimez le dossier %LOCALAPPDATA%\DownloaderYoutubeer.

7. Modifications

Cette page peut évoluer avec l'application ; la date en haut indique la dernière mise à jour. Pour toute question : slipamplemousse@gmail.com.
